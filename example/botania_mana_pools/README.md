# Botania 魔力池示例 / Mana pool example

需要 Minecraft 1.21.1、NeoForge、MMCR、Botania 和 KubeJS。将本目录的
`startup_scripts/` 和 `server_scripts/` 分别合并到实例的 `kubejs/` 对应目录，
然后重启。控制器会在启动脚本注册后生成；本示例不是 MMCR 永久内置机器。

结构是一个宽 3、高 2、深 1 的切片（`pattern` 的行从上到下）：

```text
IMO
PCQ
```

- `I`：物品输入总线；`O`：物品输出总线；`M`：基础机械外壳。
- `P`：模块化魔力输入池；`Q`：模块化魔力输出池；`C`：本示例的控制器。
- 每次配方消耗 1 铁锭、25,000 mana，100 tick 后产出 1 金锭、10,000 mana。
  魔力按整次配方规划：开始时一次性消耗，完成时一次性产出。
- 启动脚本通过现有 `ctx.ioView().manaInput()` / `manaOutputCapacity()` 读取
  快照并在控制器显示可用输入与输出空间。不存在 `ctx.io.view()` 入口；读取不会转移魔力。

输入池可以从丢入池内的魔力石板／戒指收魔；输出池可以给它们充魔。
用火花连接时应按 Botania 规则正确搭配升级（例如原生供给池使用主导火花，
模块化输入池使用普通火花）；两个普通火花不会自行进行池间转移。
普通邻接魔力发射器只能从模块化输出池取魔。
森林法杖 HUD 和液面显示真实库存，普通点击／潜行点击都不能反转池方向。
JEI 创造池图标仅标识魔力，不是配方物品或创造池合成材料，也不会参与物品转移。

## English

Merge this example's two script directories into the corresponding `kubejs/`
directories and restart. The controller is generated by the startup declaration;
this machine is not registered permanently by MMCR. Build the single 3×2 slice
shown above. One operation consumes one iron ingot and 25,000 mana, then produces
one gold ingot and 10,000 mana after 100 ticks. Mana is consumed once at start and
produced once at completion, alongside the normal item planning.

The real callback route is `ctx.ioView().manaInput()` / `manaOutputCapacity()`.
These snapshot reads transfer nothing. Input pools drain dropped tablets/rings;
output pools charge them. Spark connections require the appropriate Botania
upgrades (for example, a dominant spark on a native supply pool feeding an ordinary
spark on the modular input pool). Two ordinary sparks do not transfer by themselves.
Adjacent ordinary spreaders can draw only from modular output pools. The Wand of
the Forest shows the true stored mana and cannot reverse the fixed direction.
The JEI creative-pool icon is only a mana marker, never a crafting ingredient or
transferable item.
