# 联合接口自动 IO 控制入口设计

## 目标

优化物品、流体及物品/流体联合接口的自动 IO 控制入口，使联合接口可以直接进入对应能力的控制页面，并移除控制页面中的 `I/F` 能力切换按钮。

## 交互设计

### 主页面

- 保留现有小型自动 IO 页面按钮的位置、尺寸、外观和图标。
- 单能力接口只显示一个入口按钮。
- 物品/流体联合接口显示两个相同的小型入口按钮：
  - 第一个使用现有按钮位置，进入物品自动 IO 控制页。
  - 第二个紧邻现有按钮下方，进入流体自动 IO 控制页。
- 入口按钮不新增可见文字，能力和方向通过 tooltip 表示：
  - `物品输入控制` / `Item Input Control`
  - `物品输出控制` / `Item Output Control`
  - `流体输入控制` / `Fluid Input Control`
  - `流体输出控制` / `Fluid Output Control`

### 控制页面

- 点击入口按钮时先选中对应能力，再进入现有自动 IO 控制页面。
- 控制页面沿用当前的方向网格、启用开关和内容弹出按钮布局。
- 隐藏原有的 `I/F` 能力选择按钮。
- 当前入口按钮在控制页面变为现有的返回按钮；联合接口也只显示这一个返回按钮。
- 返回时回到主页面，不改变已保存的各能力配置。

## 实现范围

- 在 `AbstractPortScreen` 中复用现有页面按钮逻辑，增加联合接口的第二个入口按钮。
- 点击入口时设置 `selectedCapabilityId`，避免新增菜单字段、网络包或服务端状态。
- 根据选中的能力、接口方向生成 tooltip 文案。
- 删除控制页面中 `I/F` 按钮的创建和更新逻辑。
- 更新 `en_us.json` 和 `zh_cn.json` 中的自动 IO tooltip 文案。

## 非目标

- 不改变自动 IO 配置的保存格式、网络协议或服务端行为。
- 不改变控制页面的方向按钮、启用状态和弹出内容逻辑。
- 不调整主页面存储内容和玩家物品栏布局。

## 验证

- 单能力物品和流体接口各显示一个正确 tooltip 的入口按钮。
- 联合接口显示两个入口按钮，分别进入物品和流体控制页。
- 联合接口控制页面不显示 `I/F` 按钮，只显示一个返回按钮。
- 返回主页面后两个能力的入口仍可分别使用。
- 运行相关测试，并执行 Java 编译验证。
