# JEI 配方分页与默认配方设计

## 目标

优化 MMCR 的 JEI 多方块机器配方展示，使输入、输出和流体的边界清楚，并提供足够多的内建配方来验证各种展示场景。

## JEI 分类与分页

- 每台机器保留一个独立的 JEI 分类。
- 每个 `MachineRecipeDisplay` 是该分类中的一个独立 JEI 配方页，由 JEI 自带翻页控件切换。
- 分类使用固定尺寸画布，可容纳每个输入或输出分区的八行槽位。不同配方之间不改变类别尺寸。

## 槽位布局

- 配方画布分为输入区、中间处理信息区和输出区。
- 输入区固定在左侧，输出区固定在右侧；两者互不混排。
- 每个输入或输出区为四列、最多八行，单区最多 32 个可视槽位。
- 分区内先排列流体，再紧接着排列物品；仅在同一分区的槽位数超过四列时换行。
- 输入物品、输出物品、输入流体和输出流体均使用标准 18x18 JEI 槽位尺寸与统一背景。输出物品不使用视觉尺寸不同的输出槽背景。
- 中间区域显示处理箭头、配方时长、FE 输入与 FE 输出，且不与任一槽位网格重叠。

## 溢出内容

- 当任一输入或输出分区的流体与物品总数超过 32 项时，前 31 项按正常规则展示。
- 第 32 格改为 `...` 汇总槽，不代表具体物品或流体。
- 悬停汇总槽显示所有未展示内容，保留流体优先、物品随后以及原列表内顺序，并显示各项数量。
- 输入和输出分区分别独立处理溢出。

## 默认配方

- 四台默认机器：高炉、合金炉、裂解机、反应堆，各注册恰好十条内建配方，总数为 40 条。
- 配方使用原版物品和原版流体，不新增注册内容或依赖。
- 每台机器的十条配方共同覆盖：仅物品、多个物品输入、多个物品输出、仅流体输入、仅流体输出、同时含流体输入与输出、流体和物品混合输入、流体和物品混合输出、能量输入、能量输出。
- 配方 ID 使用机器名加明确语义后缀。
- `DefaultRecipes.ensureRegistered()` 继续按配方 ID 检查后注册；重复调用不得产生重复配方。

## 验证

- 布局测试覆盖输入/输出隔离、流体优先顺序、每行四列、最多八行、32 槽容量、汇总槽位置和溢出提示内容。
- JEI 分类测试确认单个显示对象对应单个 JEI 配方页，且所有槽位为统一的 18x18 尺寸。
- 默认配方测试确认每台机器十条、总计 40 条，覆盖关键的流体输入、流体输出、双向流体、能量输入和能量输出场景，并验证重复注册幂等。
- 实现完成后运行相关测试和 `./gradlew compileJava --no-daemon`。
