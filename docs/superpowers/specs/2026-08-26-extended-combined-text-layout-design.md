# 扩展联合接口文本布局设计

## 目标

整理扩展联合接口主页面的物品和流体存储文本，减少空行，并让两类内容保持统一的分组结构。

## 布局规则

标题下固定显示两个能力分组：

```text
Title
物品: ...
流体: ...
```

当某一分组没有非空存储条目时，该分组显示绿色的“无”或对应英文翻译：

```text
Title
物品: 无
流体: 无
```

当某一分组有存储条目时，分组标题单独占一行，后续逐行显示内容：

```text
Title
物品:
item line
item line
流体:
fluid line
fluid line
```

混合状态下只对空分组显示绿色“无”，有内容的分组继续显示条目。

## 实现范围

- 仅调整 `ExtendedCombinedScreen` 的主页面文本绘制顺序和行间距。
- 物品/流体条目的既有数量格式、名称和 tooltip 保持不变。
- 不修改菜单同步、存储数据、自动 IO 页面或玩家物品栏布局。

## 验证

- 物品和流体都为空时只显示两行绿色“无”。
- 只有一类有内容时，另一类显示绿色“无”。
- 两类都有内容时，分组标题和条目按顺序显示且无多余空行。
- 现有文本 UI 和相关测试通过。
