# 机器等级 UI 与配方展示设计

## 范围

为机器等级系统补充控制器界面与 JEI 的可视化信息，并让内置热能冶炼炉的五个示例配方具有可观察的差异。Jade 不在本次范围内。

## 控制器界面

控制器界面从控制器已匹配的等级快照中读取每个等级类型的实际方块状态。等级行显示在状态行之后、上次失败行之前，格式为：

`热能冶炼线圈: 铁块`

前半部分使用 `LevelType` 注册时提供的显示名称，后半部分使用匹配方块的显示名称。没有匹配等级时不显示该行。

## JEI 配方页

JEI 在能量消耗文字的下方显示每项配方等级需求。每项需求只显示一行纯文本，不显示代表物品。

显示格式为：

`热能冶炼线圈: 铁块`

类型名称采用浅绿色，等级名称保持普通文本颜色。对于“要求某等级及以上”的配方，客户端依据游戏时间每秒轮播一次同一类型中从最低等级到最高等级的所有等级，再反向轮播回最低等级。例如铁块及以上依次显示铁块、金块、钻石块、金块、铁块。不同 JEI 页面使用相同的客户端游戏时间，因此在同一时刻同步。

## 内置热能冶炼炉配方

五个默认热能冶炼炉配方保持由无等级门槛、铜、铁、金、钻石线圈逐档解锁的关系。每档分别提高输入材料、能耗、加工时长和产物价值，使玩家能在 JEI 与游戏中区分并验证每个配方及等级门槛。

## 验证

- 增加或更新控制器界面、JEI 等级展示和默认配方的针对性测试。
- 运行 `./gradlew compileJava --no-daemon`。
- 运行相关测试任务；若测试任务受现有环境限制，记录实际结果。
